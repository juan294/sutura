## Incident: the bind push could not pass its own gate

- The pre-push `release:case-lab check` read the controller commit's
  `release.json` only from GitHub (contents API, then fetch-by-sha). The pin
  commit names the bind commit, and in the pre-push hook neither commit has
  reached GitHub yet, so the check reported it `unreadable` and refused the
  one push that completes a cycle. v0.3.1 did not meet this because the
  controller check (`e570b0c`) landed after its bind commit was pushed
- Fix `1ff7c9d`: read the local object first, then fall back to the API and
  the fetch; covered by a new test in `scripts/release-case-lab.test.mjs`.
  The hook was not bypassed
