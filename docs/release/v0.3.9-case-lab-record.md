# v0.3.9 Case Lab record

Date: 2026-10-05

Status: v0.3.9 is released and published. The Case Lab is bound to v0.3.9 and
deployed with live runs enabled. The live `python-repair` smoke published a
`fixed` result with its case file attached. Fleet re-pin: 16 of 17 repositories
are on v0.3.9. chapa #1369 waits for the owner's merge, and the three-day fleet
observation starts after that merge.

v0.3.9 bounds triage by a cumulative sandbox-time budget (default 240 sandbox
seconds). When the failing command calls a test runner directly, triage first
reruns only the failing test file. v0.3.9 also resolves package-relative
vitest failures in workspaces (`26e8aa7`). Plan:
[bounded, focused triage](../plans/2026-10-03-sutura-bounded-focused-triage.md),
phase 3.
